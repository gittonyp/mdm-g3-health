# Vue SPA + Adaptive Vital Display Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the five static pages with one Vue 3 SPA and remove every fixed clinical range from `/live` in favour of adaptive, baseline-aware wording.

**Architecture:** Vite builds `frontend/` into hashed assets under `/static/app/`. FastAPI keeps every `/api/*` route unchanged, serves the built assets, and returns the SPA shell for the five page paths. `/live` moves into a route-split Vue view whose MQTT client exists only while that view is mounted.

**Tech Stack:** Vue 3, vue-router 4, Vite 5, mqtt.js 5, Vitest, FastAPI, Python unittest.

**Spec:** `docs/superpowers/specs/2026-10-24-vue-spa-design.md`

```python
SPA_DIR = config.ROOT_DIR / "frontend" / "dist"
SPA_PREFIXES = {"clinic", "care", "history", "live"}
SPA_FALLBACK = """<!doctype html><html lang="en"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>Remote Care</title><link rel="icon" href="data:,"></head>
<body><div id="app"></div></body></html>"""


def spa_shell():
    index = SPA_DIR / "index.html"
    if index.exists():
        return FileResponse(index, headers={"cache-control": "no-cache"})
    return HTMLResponse(SPA_FALLBACK)


@app.get("/{full_path:path}", include_in_schema=False)
def spa(full_path: str):
    if full_path.split("/", 1)[0] not in SPA_PREFIXES:
        raise HTTPException(status_code=404)
    return spa_shell()
```

- [ ] **Step 3: Implement the helpers**

State titles/hints:

| state | title | hint | cls |
|---|---|---|---|
| normal | Vitals within your baseline | Adaptive range learned from this patient. | ok |
| measuring | Acquiring signal | Keep the finger still on the sensor. | warn |
| no_finger | Sensor not in contact | Place a finger on the pulse oximeter. | warn |
| learning | Learning your baseline | Keep still while the monitor adapts. | warn |
| watch | Early warning | Vitals are drifting from the personal baseline. | warn |
| alert | Abnormal vitals | Sustained deviation from the personal baseline. | bad |
| emergency | Emergency | Vitals are far outside safe limits. Check now. | bad |
| stress | Low HRV | Stress or fatigue detected while resting. | warn |
| fall | Possible fall detected | Check on the patient now. | bad |
| offline | No signal from device | Waiting for the monitor to reconnect. | warn |

`vitalChip` maps `normal → Normal/ok`, `learning → Learning`, `watch → Watch/warn`, `alert → Alert/bad`, `emergency → Emergency/bad`, `stress → Stress/warn`, `fall → Fall/bad`, `measuring → Acquiring/warn`, `no_finger → No finger/warn`, `offline → Offline`. Missing value always `—`.

`sparkRange` pads observed min/max by 10 %; with fewer than two values returns `hr:[50,120]`, `spo2:[90,100]`, `hrv:[0,100]`, `temp:[35,40]`.
